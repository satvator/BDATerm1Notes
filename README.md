## 🚀 How to Access & Use This Repository Offline

If you want to study offline, run scripts locally, or keep a copy on your laptop or mobile device, choose one of the options below:

### Option 1: Clone using Git (Recommended)

If you have Git installed on your computer, run the following command in your terminal/command prompt:

```bash
git clone https://github.com/satvator/BDATerm1Notes.git
cd BDATerm1Notes
```

To pull the latest updates whenever new notes or fixes are added, run:

```bash
git pull origin main
```

### Option 2: Download as a ZIP File (No Git Required)

1. Navigate to the main repository page: `github.com/satvator/BDATerm1Notes`.
2. Click the green `Code` button located at the top right of the file list.
3. Select `Download ZIP`.
4. Extract the downloaded `.zip` file on your computer to access all Markdown files, Jupyter Notebooks, and datasets offline.

### Option 3: Read on Mobile / Tablet

All notes are written in GitHub-Flavored Markdown (`.md`), which renders automatically into formatted web pages with LaTeX mathematical equations, tables, and highlighted code blocks.

* Simply bookmark the link on your mobile browser or open it via the official GitHub Mobile App for quick revision on the go.

## 💡 How to Use the Study Manuals During Exams

1. **Use `Ctrl + F` (or `Cmd + F` on Mac):** Search for specific functions, R/Python error names, or algorithm keywords.
2. **Follow the Worked Examples:** Step-by-step mathematical calculations (e.g., $k$-means centroids, confusion matrix metrics, Apriori lift/uplift calculations) are formatted as template guides for numerical questions.
3. **Check the Exam Pitfalls Boxes:** Review the highlighted `⚠ Exam Tip` and `⚠ Common Mistake` callout boxes before answering evaluation questions.
